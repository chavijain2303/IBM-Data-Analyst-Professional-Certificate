# Course 10: Generative AI – Enhance Your Data Analytics Career

## 📖 Overview

This repository contains my notes, hands-on labs, guided practice project, assignments, and supporting resources completed as part of **Course 10 – Generative AI: Enhance Your Data Analytics Career** from the **IBM Data Analyst Professional Certificate**.

The course introduces **Generative AI** and demonstrates how it can enhance the work of data analysts by automating repetitive tasks, accelerating data preparation, assisting with code generation, creating visualizations, building dashboards, and generating business narratives. It also emphasizes prompt engineering, Responsible AI, ethical considerations, and industry-specific applications of Generative AI.

---

## 🎯 Learning Objectives

After completing this course, I can:

- Understand the fundamentals of Generative AI and Large Language Models (LLMs)
- Apply prompt engineering techniques to improve AI-generated outputs
- Use Generative AI to generate Python and SQL code
- Automate data preparation and exploratory data analysis (EDA)
- Create charts, dashboards, and business reports with AI assistance
- Apply Responsible AI principles to real-world analytics
- Identify ethical, legal, and privacy considerations when using AI
- Integrate Generative AI into end-to-end data analytics workflows
