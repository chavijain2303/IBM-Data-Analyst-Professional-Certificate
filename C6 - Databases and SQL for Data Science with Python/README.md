## Overview

This repository contains my notes, hands-on labs, assignments, practice exercises, and solutions completed as part of **Course 6 – Databases and SQL for Data Science with Python** from the **IBM Data Analyst Professional Certificate**.

The course provides a comprehensive introduction to relational databases, SQL programming, database design, cloud databases, and integrating SQL with Python for data analysis. It covers everything from basic SQL queries to advanced database concepts such as joins, subqueries, views, stored procedures, transactions, and database connectivity using Python.
