## Overview

This repository contains my notes, labs, assignments, and final project completed as part of **Course 5 – Python Project for Data Science** from the **IBM Data Analyst Professional Certificate**.

The course focuses on applying Python programming skills in a real-world data science scenario. Instead of learning new syntax, it emphasizes using Python libraries to extract, clean, analyze, and visualize financial data from multiple sources.

The final project simulates the role of a **Data Analyst/Data Scientist** working for an investment firm, where historical stock prices and company revenue data are collected and analyzed to build an interactive dashboard.

---

# Course Objectives

After completing this course, I learned how to:

- Extract financial data using Python APIs
- Perform web scraping using BeautifulSoup
- Parse HTML documents and extract structured data
- Work with tabular data using Pandas
- Clean and preprocess real-world datasets
- Visualize stock price and revenue trends
- Build dashboards for financial analysis
- Combine data from multiple sources into a single analytical workflow
