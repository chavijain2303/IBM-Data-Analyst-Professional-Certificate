# Course 3: Data Visualization and Dashboards with Excel and Cognos

## 📖 Overview

This repository contains my notes, hands-on labs, assignments, and final project completed as part of **Course 3 – Data Visualization and Dashboards with Excel and Cognos** from the **IBM Data Analyst Professional Certificate**.

The course focuses on transforming raw data into meaningful visual insights using **Microsoft Excel** and **IBM Cognos Analytics**. It covers visualization principles, Excel charts, PivotTables, PivotCharts, interactive dashboards, geospatial maps, and business intelligence dashboards using Cognos Analytics.

---

# 🎯 Learning Objectives

After completing this course, I can:

- Apply data visualization best practices.
- Select appropriate chart types for different datasets.
- Create professional visualizations using Microsoft Excel.
- Build PivotTables and PivotCharts for data summarization.
- Design interactive dashboards using Excel.
- Develop AI-assisted dashboards in IBM Cognos Analytics.
- Create calculations and drill-down navigation paths.
- Apply dashboard filters and cross-filtering techniques.
- Build dashboards that communicate actionable business insights.
