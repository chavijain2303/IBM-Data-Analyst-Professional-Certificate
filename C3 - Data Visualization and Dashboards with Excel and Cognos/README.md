# Course 3: Data Visualization and Dashboards with Excel and Cognos Analytics

This course is part of the **IBM Data Analyst Professional Certificate** and focuses on
transforming analytical results into impactful visualizations and interactive dashboards
using **Microsoft Excel** and **IBM Cognos Analytics**.

The course emphasizes practical dashboard development using real-world business scenarios,
helping analysts communicate insights effectively to decision-makers.

---

## 📘 Course Overview

Data visualization plays a critical role in analytics by turning complex datasets into
clear, actionable insights. This course develops the ability to design effective charts,
build interactive dashboards, and communicate business performance visually.

Learners work with both spreadsheet-based visualization and modern BI tools to create
professional, decision-ready dashboards.

---

## 🧠 Key Concepts Covered

### 🔹 Module 1: Visualizing Data Using Spreadsheets
- Importance of visualization in data storytelling
- Introduction to Excel charting tools
- Creating basic charts:
  - Line charts for trends
  - Pie charts for proportions
  - Bar and column charts for comparisons
- Introduction to Pivot Tables for data summarization
- Using Pivot Charts for visual analysis
- Drill-down and drill-up exploration of summarized data
- Hands-on labs for building practical visualizations

---

### 🔹 Module 2: Creating Visualizations and Dashboards with Spreadsheets
- Creating advanced Excel charts:
  - Treemaps
  - Scatter charts
  - Histograms
  - Filled map charts
  - Sparklines
- Overview of additional advanced chart types
- Dashboard design fundamentals:
  - Purpose of dashboards
  - Key components and KPIs
  - Interactive dashboard principles
- Building dashboards in Excel using:
  - Charts
  - Pivot tables
  - Map visuals
  - Sparklines
  - Slicers and filters
- Dashboard design best practices:
  - Avoid clutter
  - Maintain visual consistency
  - Highlight key insights only
- Creating presentation-ready dashboards

---

### 🔹 Module 3: Creating Visualizations and Dashboards with Cognos Analytics
- Introduction to IBM Cognos Analytics as a BI platform
- Setting up and navigating Cognos Analytics
- Uploading datasets and preparing dashboards
- Creating dashboards using:
  - Drag-and-drop visualizations
  - Manual visualization selection
  - AI assistant-generated visualizations
- Creating KPI summaries and interactive visuals
- Applying dashboard filters and cross-filtering
- Advanced dashboard features:
  - Calculated fields and metrics
  - Navigation paths for drill-down analysis
  - Excluding data points
  - Top/Bottom filters
  - Infographic enhancements
- Designing professional, interactive dashboards

---

### 🔹 Module 4: Final Project
- Creating visualizations using Excel
- Building dashboards using Cognos Analytics
- Delivering business insights through visual storytelling
- Submitting project deliverables for evaluation
