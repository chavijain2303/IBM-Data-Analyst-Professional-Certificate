# Course 4: Python for Data Science, AI & Development

## 📖 Overview

This repository contains my notes, hands-on labs, practice exercises, and learning resources completed as part of **Course 4 – Python for Data Science, AI & Development** from the **IBM Data Analyst Professional Certificate**.

The course introduces Python programming from the ground up and focuses on building the programming skills required for data science, artificial intelligence, and data analytics. It covers Python fundamentals, data structures, control flow, functions, object-oriented programming, file handling, NumPy, Pandas, APIs, and web scraping.

---

# 🎯 Learning Objectives

After completing this course, I can:

- Write Python programs using fundamental programming concepts.
- Work with Python data types and data structures.
- Implement conditional statements and loops.
- Create reusable functions and classes.
- Read from and write to files.
- Manipulate data using NumPy and Pandas.
- Retrieve data using REST APIs.
- Extract information from websites using web scraping.
- Build Python solutions for real-world data analysis tasks.
