# Course 4: Python for Data Science, AI & Development

This course is part of the **IBM Data Analyst Professional Certificate** and builds a strong foundation in Python programming for data science and analytics applications.

The course focuses on writing Python programs, working with data using popular libraries, and collecting real-world data through APIs and web scraping techniques.

---

## 📘 Course Overview

Python is one of the most widely used languages in data science and analytics. This course introduces Python fundamentals and gradually progresses toward data manipulation, file handling, numerical computing, and data collection from external sources.

Hands-on labs and practice exercises are used extensively to develop practical programming skills.

---

## 🧠 Key Concepts Covered

### 🔹 Module 1: Python Basics
- Introduction to Python and its ecosystem
- Working with Jupyter Notebook
- Writing and executing Python programs
- Core data types:
  - Integers, floats, strings, and booleans
- Expressions and variables
- String operations and formatting
- Type conversion
- Basic Python syntax and programming practices

---

### 🔹 Module 2: Python Data Structures
- Lists and tuples
- Indexing and slicing
- Mutable vs immutable data structures
- Dictionaries for key-value data storage
- Sets and their properties
- Removing duplicates using sets
- Data organization using compound data structures

---

### 🔹 Module 3: Python Programming Fundamentals
- Conditional statements (if, else, elif)
- Logical and comparison operators
- Looping constructs:
  - for loops
  - while loops
  - enumerate and range usage
- Functions:
  - Built-in functions
  - User-defined functions
  - Function parameters and return values
  - Scope and global variables
- Exception handling using try–except blocks
- Object-Oriented Programming concepts:
  - Classes and objects
  - Attributes and methods
  - Constructors
  - Creating and using custom classes

---

### 🔹 Module 4: Working with Data in Python
- Reading and writing files using Python
- File handling best practices
- Introduction to Pandas library
- Loading CSV and Excel data
- Creating and manipulating DataFrames
- Data selection and filtering
- Saving processed data
- Introduction to NumPy:
  - 1D and 2D arrays
  - Vector and matrix operations
  - Mathematical operations
- Basic plotting using NumPy and Matplotlib

---

### 🔹 Module 5: APIs and Data Collection
- Understanding APIs and how they work
- REST APIs and HTTP requests
- Making API calls using Python
- Extracting data from web services
- Working with JSON responses
- Converting API data to DataFrames
- Time-series data processing
- Introduction to web scraping techniques
- Data extraction from online sources
- Practice project: Data extraction and processing
