# Course 7: Data Analysis with Python

## Overview

This repository contains my notes, hands-on labs, practice exercises, assignments, and final projects completed as part of **Course 7 – Data Analysis with Python** from the **IBM Data Analyst Professional Certificate**.

The course focuses on applying Python to perform the complete data analysis workflow—from importing and cleaning datasets to exploratory data analysis (EDA), data visualization, predictive modeling, and model evaluation. Through real-world datasets such as Used Car Pricing, Laptop Pricing, Insurance Charges, and House Sales, I gained practical experience in preparing data, developing machine learning models, and interpreting analytical results.
