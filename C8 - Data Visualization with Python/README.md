# Course 8: Data Visualization with Python

## Overview

This repository contains my notes, hands-on labs, assignments, dashboards, and final projects completed as part of **Course 8 – Data Visualization with Python** from the **IBM Data Analyst Professional Certificate**.

The course focuses on transforming raw data into meaningful visual insights using Python. It covers the complete visualization workflow—from selecting appropriate chart types and creating publication-quality plots with **Matplotlib** and **Seaborn**, to building interactive maps with **Folium** and dynamic dashboards using **Plotly** and **Dash**.

Through real-world datasets such as **Canada Immigration**, **Australian Wildfire Activities**, **US Airline Performance**, and **Automobile Sales**, I developed practical skills in exploratory visualization, storytelling, and dashboard development.

After completing this course, I can:

- Apply visualization techniques to real-world datasets
