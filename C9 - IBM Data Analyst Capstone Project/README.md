# IBM Data Analyst Capstone Project

## Overview

This repository contains my notes, hands-on labs, assignments, dashboards, presentations, and final project completed as part of the **IBM Data Analyst Capstone Project**, the final course of the **IBM Data Analyst Professional Certificate**.

The capstone project integrates all the skills acquired throughout the certificate program into a single end-to-end analytics project. Using the **Stack Overflow Developer Survey** dataset, I collected data, performed data wrangling, exploratory data analysis (EDA), created visualizations, built interactive dashboards, and presented actionable business insights.

---

# Project Objectives

The primary objectives of this capstone project are to:

- Collect data from multiple sources
- Clean and prepare datasets for analysis
- Perform exploratory data analysis (EDA)
- Identify current and future technology trends
- Visualize analytical findings
- Build interactive dashboards
- Present insights through professional reports and presentations
- Support business decision-making using data
