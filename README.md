# IBM Data Analyst Professional Certificate

This repository documents my learning journey through the **IBM Data Analyst Professional Certificate**, a comprehensive 11-course specialization designed to develop job-ready data analytics skills. The program combines theoretical concepts with extensive hands-on labs, real-world projects, and portfolio-building assignments using industry-standard tools and technologies.

Throughout this certification, I gained practical experience in data collection, data cleaning, SQL, Python programming, exploratory data analysis, data visualization, dashboard development, business intelligence, generative AI, and interview preparation.

| Course | Topics Covered |
|---------|----------------|
| **C1 - Introduction to Data Analytics** | Data Analytics Fundamentals, Data Ecosystem, Databases, SQL, Python, Data Visualization |

| **C3 - Data Visualization and Dashboards with Excel and Cognos** | Charts, Dashboards, PivotCharts, IBM Cognos Analytics, Business Intelligence |
| **C4 - Python for Data Science, AI & Development** | Python Programming, Data Structures, NumPy, Pandas, APIs, Web Scraping |
| **C5 - Python Project for Data Science** | Web Scraping, API Integration, Data Collection, Data Visualization, Stock Data Analysis |
| **C6 - Databases and SQL for Data Science with Python** | SQL Queries, Joins, Views, Functions, Database Design, Python Database Connectivity |
| **C7 - Data Analysis with Python** | Data Wrangling, EDA, Statistical Analysis, Regression, Model Evaluation |
| **C8 - Data Visualization with Python** | Matplotlib, Seaborn, Plotly, Folium, Interactive Dashboards |
| **C9 - IBM Data Analyst Capstone Project** | Real-world Data Collection, Analysis, Visualization, Dashboard Development, Final Portfolio Project |
